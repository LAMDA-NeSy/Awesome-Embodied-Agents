# Environments and Interfaces

These resources support embodied code-agent experiments. An environment's presence here does not imply that every agent evaluated on it generates code.

| Resource | Domain | Interface or Purpose | Official Resource |
| :--- | :---: | :--- | :--- |
| **Mineflayer** | Game | JavaScript API for Minecraft bots, world queries, and actions | [💻&nbsp;Repository](https://github.com/PrismarineJS/mineflayer) |
| **MineDojo** | Game | Minecraft environment and resources for open-ended embodied-agent research | [💻&nbsp;Repository](https://github.com/MineDojo/MineDojo) |
| **CaP-Gym / CaP-X** | Robot | Program execution over robot perception and control primitives | [🌐&nbsp;Project](https://capgym.github.io/) |
| **robosuite** | Robot | Robot manipulation simulation used in code-policy experiments | [💻&nbsp;Repository](https://github.com/ARISE-Initiative/robosuite) |
| **LIBERO** | Robot | Manipulation tasks and transfer evaluation; record the exact variant used by each paper | [💻&nbsp;Repository](https://github.com/Lifelong-Robot-Learning/LIBERO) |
