| Field | Value |

| Focus | Sections 4–6; Tables 4, 5, and 7 |

The survey connects datasets, models, harnesses, and benchmarks. Its harness analysis covers perception, action, reasoning, real-time reactivity, memory, and adaptation. Evaluation should distinguish interface privilege, timing, coverage, and transfer.

For this collection, model-weight learning belongs in Model Training; runtime, code, and memory contributions belong in Harness; evaluation suites belong in Benchmark. Hybrid papers receive one primary entry. The [game-agent guide](../docs/GAME_AGENT_GUIDE.md) records the selected papers and original-source checks.
